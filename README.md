# FinSight

Personal-finance app built with Spring Boot 3.5, Vaadin Flow 24 and PostgreSQL (Java 21).

```
finsight-backend/   the application (REST API + Vaadin UI, one process)
render.yaml         one-click Render deployment (web service + free Postgres)
DEPLOYMENT.md       deployment details and free-tier notes
```

The old React frontend (`finsight-frontend`) was reference-only and is not part of this repo.
